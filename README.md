# 卓上NMR 測定時間・性能比較アプリ

このStreamlitアプリは、卓上NMR装置の ^1H感度、推定測定時間、分解能、設置面積、体積、重量 などを比較するためのツールです。
<img width="650" height="293" alt="MG Competition2" src="https://github.com/user-attachments/assets/7127f48e-6540-465a-893a-6e60eab1050c" />

## 主な機能

- 2機種の卓上NMRを並列比較
- ^1H感度から必要測定時間を推定
- 他社機種の任意の感度数値入力による比較
- 分解能（Hz）の比較（Spinsolveのみ）
- サイズ比較表示：
  - 3Dサイズ比較
  - 設置面積オーバーレイ表示
  - 比率サマリー表示
- 1日あたりの測定処理数を試算

## 測定時間計算
<img width="650" height="314" alt="MG App Top" src="https://github.com/user-attachments/assets/4cef5bd8-8eca-492a-a3bf-74816e3b0fe5" />

推定測定時間は、以下の関係式に基づいて計算されます。

必要測定時間 = 基準測定時間 × (基準感度 / 比較対象感度)^2
本計算は、S/N比が概ね測定時間の平方根に比例することを前提としています。
そのため、感度が高い装置ほど、同等のS/N比を得るために必要な測定時間は短くなります。
たとえば、感度が2倍であれば、必要測定時間は理論上約1/4になります。

本アプリでは、Spinsolve各モデルを、^1H(プロトン)感度・推定測定時間・分解能・サイズの観点から比較できます。任意の仕様値を入力して検討中の装置との相対比較も可能です。

## 注意事項
本ツールの結果は、装置選定における一つの判断指標です。
実際の測定時間やS/N比は、サンプル濃度、測定核種、溶媒、ピーク形状、測定条件、データ処理条件などによって変動します。
そのため、本アプリの計算結果は、同一条件下での相対比較を目的とした目安としてご利用ください。

最終的な装置選定は、測定対象、核種、分解能要求、サンプル数、設置環境、ご予算などを総合的に考慮してご判断ください。
